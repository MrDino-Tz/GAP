
# GAP - GPA Calculator

A comprehensive GPA calculation platform designed for IAA students to accurately track and manage their academic performance across multiple programmes and semesters.

## 🎯 About

**GAP (GPA Calculator)** is a modern, responsive web application that helps students calculate their Semester GPA and Cumulative GPA (CGPA) with precision based on official IAA grading systems. The platform supports multiple academic programmes and provides detailed performance analytics.

**Developed by:** DTC Group  
**Location:** Tanzania  
**Target Institution:** Institute of Accountancy Arusha (IAA)

## 🚀 Features

### 📊 Core Functionality
- **Accurate GPA Calculation** - Based on official NTA grading scales
- **Multiple Programme Support** - 13+ academic programmes across all levels
- **Semester & CGPA Tracking** - Track individual semester and cumulative performance
- **PDF Export** - Generate detailed academic reports
- **Mobile Responsive** - Optimized for all devices

### 🎓 Academic Programmes
- **Certificate Level (NTA 4)** - Certificate in Accountancy
- **Diploma Level (NTA 5)** - Multiple diploma programmes
- **Bachelor Level (NTA 7)** - 8 bachelor's degree programmes including BBM
- **Masters Level (NTA 9)** - 4 master's degree programmes

### 🤖 Smart Features
- **AI Academic Chatbot** - Powered by Google Gemini for academic guidance
- **Progressive Selection** - Smart filtering based on academic level
- **Real-time Calculations** - Instant GPA updates as grades are entered

## 📱 Technology Stack

- **Frontend:** React 18 + TypeScript
- **Build Tool:** Vite
- **UI Framework:** shadcn/ui + Radix UI
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **PDF Generation:** jsPDF
- **AI Integration:** Google Gemini API

## 🛠️ Installation & Setup

### Prerequisites
- Node.js 16+ 
- npm or yarn

### Quick Start

```bash
# Clone the repository
git clone <YOUR_GIT_URL>

# Navigate to project directory
cd GAP

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```



## 📖 Usage Guide

### Basic Workflow
1. **Select University** - Choose your institution (default: IAA)
2. **Select Academic Level** - Certificate, Diploma, Bachelor, or Masters
3. **Select Programme** - Choose your specific academic programme
4. **Select Semester** - Pick the semester you want to calculate
5. **Enter Grades** - Select grades for each module
6. **Calculate GPA** - View your semester GPA and save results
7. **Track CGPA** - Monitor cumulative performance across semesters

### Advanced Features
- **Export Reports** - Generate PDF reports for individual semesters
- **Chat with AI** - Get academic advice from the AI chatbot
- **Compare Performance** - Track GPA trends over time
